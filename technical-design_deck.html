Perficent Agentic RAG

Combined technical summary and architecture diagram for engineering, operations, and broker-platform stakeholders.

1) Technical Summary

Perficent Agentic RAG is a .NET 10, Blazor-first platform for broker-focused investment research. It orchestrates chat, market/filing/news retrieval, durable memory, observability, and evaluation gates.

Primary Objectives

  • Deliver professional, easy-to-read, advisor-ready responses.
  • Support ticker-based and dataset-driven research workflows.
  • Persist session context and durable facts for continuity.
  • Capture end-to-end observability with ordered metadata signals.
  • Enforce quality with Golden Gate, Developer, and PromptWise evaluation modes.

Solution Layers

Blazor Web UI
Minimal API Layer
Agent Orchestration
Tool Services
SQLite Persistence
External Market/SEC/News/Search

Key Runtime Flows

  • Chat: Request validation → intent/context prep → MAF streaming or fallback → HTML response rendering via Markdig.
  • Observability: API, agent, workflow, and tool-call events captured in execution order with metadata.
  • Evaluation: Golden Gate (production signals), Developer (dataset prompts), PromptWise (single prompt checks).

Release Gate Interpretation

  • Pass: weighted score meets configured threshold and all required metric thresholds pass.
  • Fail: weighted score and/or one or more required metrics are below threshold.
  • Human Review: required when risk signals or gate outcomes indicate additional oversight.
